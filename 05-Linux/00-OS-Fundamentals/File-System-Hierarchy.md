# Linux File System Hierarchy Standard (FHS)

Unlike Windows which uses drive letters (`C:\`, `D:\`), Linux mounts all filesystems under a single unified directory tree starting at the root `/`. Understanding where things live is crucial for troubleshooting applications and reading logs.

## The Root Directory `/`

Everything stems from the root. Only the `root` user has write permissions directly under `/`.

### 1. `/bin` and `/sbin` (Binaries)
- `/bin`: Essential user command binaries (e.g., `ls`, `cat`, `bash`, `ping`). Available to all users.
- `/sbin`: System administration binaries (e.g., `fdisk`, `iptables`, `sysctl`). Typically requiring root privileges.
- *Note: On modern systems (like Ubuntu 20.04+), these are often symlinks to `/usr/bin` and `/usr/sbin`.*

### 2. `/etc` (Configuration)
The central nervous system of a Linux server. **Host-specific system-wide configuration files.**
- `/etc/passwd`: User account information.
- `/etc/fstab`: Filesystem mount definitions.
- `/etc/nginx/nginx.conf`: Configuration file for the NGINX web server.
- `/etc/systemd/system/`: Custom systemd service unit files.

### 3. `/var` (Variable Data)
Files to which the system writes data during the course of its operation.
- `/var/log`: System and application logs.
  - `/var/log/syslog` (Ubuntu) or `/var/log/messages` (RHEL): General system logs.
  - `/var/log/auth.log`: Authentication attempts (SSH logins, sudo usage).
- `/var/lib`: State information (e.g., databases like MySQL or PostgreSQL store their raw data files in `/var/lib/mysql`).
- `/var/run`: Process ID (PID) files for running processes.

### 4. `/home` and `/root` (User Directories)
- `/home/<username>`: Personal directories for standard users. Contains `.bashrc`, `.ssh/authorized_keys`, etc.
- `/root`: The home directory for the `root` user. (It is NOT `/home/root`).

### 5. `/tmp` (Temporary Files)
- A world-writable directory for temporary files. 
- **Important:** `/tmp` is typically wiped clean on every system reboot. Do not store permanent data here.

### 6. `/usr` (User Programs)
Read-only user data.
- `/usr/bin` & `/usr/sbin`: The vast majority of installed programs.
- `/usr/local/bin`: Locally compiled or manually installed binaries (e.g., if you download Terraform or kubectl manually, put them here).

### 7. `/opt` (Optional Software)
Used for monolithic third-party applications that don't split their files across `/bin`, `/lib`, and `/etc`.
- For example, installing an application like Splunk or a proprietary Java agent often places everything under `/opt/splunk/`.

### 8. `/dev` (Device Files)
In Linux, "everything is a file." Hardware devices are represented as files here.
- `/dev/sda` or `/dev/nvme0n1`: Hard drives.
- `/dev/null`: The "black hole". Anything written here is discarded. Often used to suppress output: `command > /dev/null 2>&1`.

### 9. `/proc` (Process and Kernel Information)
A virtual filesystem generated by the kernel in memory.
- `/proc/cpuinfo`: CPU specifications.
- `/proc/meminfo`: Memory usage statistics.
- `/proc/<PID>/`: Information about a specific running process.
